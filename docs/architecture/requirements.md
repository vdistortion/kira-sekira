# Требования и границы продукта

## Основной сайт

Основной сайт представляет фотографа и должен содержать:

- имя/логотип в текущем текстовом виде;
- главное фото;
- краткое позиционирование и блок «Обо мне»;
- опыт работы;
- список альбомов без обязательной группировки по категориям;
- цены/услуги, редактируемые в Directus;
- видео фотографа и бэкстейджи по внешним ссылкам;
- отзывы;
- контакты и, возможно позже, форму заявки.

Актуальные цены и тексты берутся из Wfolio, а не из старого статичного сайта.

## Сайты моделей

Один Angular-шаблон обслуживает неограниченное количество моделей по
поддоменам. Профиль модели может содержать:

- имя;
- поддомен;
- главное фото;
- описание;
- параметры;
- город/локацию (необязательно);
- татуировки (необязательно);
- собственные альбомы;
- видео по внешним ссылкам;
- общие контакты фотографа.

Пустые необязательные значения на сайте не отображаются.

## Контент и файлы

- Одна галерея может быть привязана к нескольким сайтам.
- У галереи есть порядок, обложка, slug и необязательное описание.
- У фотографий внутри галереи есть порядок.
- Изображения автоматически конвертируются в WebP с максимальной стороной
  1000 px.
- Видео не загружаются в Directus, а хранятся на внешней площадке и задаются
  ссылками.

## Админка

Заказчица редактирует весь проектный контент:

- основной сайт;
- модели;
- галереи и фотографии;
- видео;
- цены;
- отзывы;
- контакты.

Системные настройки Directus, пользователей, роли, схему и инфраструктуру она
не редактирует. Свой пароль пользователь меняет через профиль.

## Не входит в текущий объём

- раздел историй/публикаций;
- отдельные домены моделей;
- мультиязычность;
- хранение видео на VPS;
- обязательная форма заявок вместо контактных ссылок.
