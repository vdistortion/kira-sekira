# Админка и рабочие сценарии

## Заказчица

Работает только с контентом проекта:

1. Открывает нужную коллекцию или singleton.
2. Редактирует текст, цену, ссылку или фотографию.
3. Загружает изображение — hook автоматически создаёт WebP.
4. Меняет порядок галерей и фотографий.
5. Публикует/скрывает готовый контент простым переключателем, когда такой
   статус будет добавлен.

Системные разделы Directus для неё закрыты.

## Галерея

1. Создать альбом.
2. Указать название, slug, обложку и при необходимости описание.
3. Загрузить фотографии.
4. Расставить порядок фотографий.
5. Привязать альбом к одному или нескольким сайтам.
6. Включить альбом для показа после готовности.

## Модель

1. Создать профиль модели.
2. Указать поддомен.
3. Заполнить профиль и необязательные поля.
4. Привязать собственные галереи и видео.
5. Включить профиль после готовности.

## Видео

Видео размещаются на внешней площадке. В Directus хранится только URL и
название. Одно видео можно связать с основным сайтом и несколькими моделями.

## Заявки

На первом этапе достаточно кнопок телефона, Telegram и WhatsApp. Форма заявки
может быть добавлена позже через защищённый Directus endpoint с отправкой в
Telegram-бота или email. Токен бота не должен попадать в браузер.

## Начальное наполнение

Сиды используются для локального демо и первоначального bootstrap. Production
контент после заполнения в Directus живёт в PostgreSQL и не зависит от запуска
сидов на каждом деплое.
