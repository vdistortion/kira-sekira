# Открытые вопросы

## Решить позже с фотографом

1. Актуальные цены и состав услуг — структура поддерживает редактирование из
   админки, но значения нужно сверить с Wfolio.
2. Нужно ли добавлять форму заявки или пока оставить кнопки контактов.
3. Нужны ли дополнительные поля модели кроме города и татуировок.
4. Нужно ли добавлять booking-ссылку на сайте модели.
5. Нужно ли переносить отзывы из Wfolio сразу или сделать это вручную позже.
6. Нужна ли отдельная подпись/описание для каждой фотографии.

## Технические следующие шаги

1. Добавить необязательные поля `location` и `tattoos` в `models`.
2. Добавить необязательное `description` в `galleries`.
3. Определиться с простым флагом публикации для моделей и галерей, например
   `enabled`.
4. Привести существующие значения контактов к готовым URL и проверить ссылки
   в frontend.
5. При необходимости автоматически формировать alt-текст из названия галереи
   и имени файла.
6. Отдельно решить, нужна ли форма заявки через защищённый backend endpoint.
