# Принятые решения

| Область               | Решение                                                                                                              |
| --------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Источник контента** | Wfolio — актуальный источник основного сайта, пока подписка оплачена.                                                |
| **Сайты**             | Один основной сайт и универсальный шаблон моделей на `*.kira-sekira.ru`.                                             |
| **Галереи**           | Самостоятельная сущность; один альбом можно привязать к нескольким сайтам без копирования фото.                      |
| **Видео**             | Нужны на основном сайте и сайтах моделей; в Directus хранятся внешние ссылки, не видеофайлы.                         |
| **Контакты**          | Telegram и WhatsApp хранятся как готовые URL.                                                                        |
| **Время работы**      | Только `contacts.working_hours`; поле необязательное и может быть пустым.                                            |
| **Логотип**           | Пока используется текстовый логотип с текущим шрифтом; картинка логотипа в Directus не нужна.                        |
| **Админка**           | Заказчица редактирует весь контент проекта, но не системные настройки, пользователей, роли и схему Directus.         |
| **Отзывы**            | Нужны на основном сайте; перенос из Wfolio можно сделать позже вручную.                                              |
| **Локальные данные**  | Сиды используются для демо и начального наполнения. Production-данные в Directus не пересоздаются при каждом деплое. |
