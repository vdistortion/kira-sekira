# Перенос прототипа на events.kira-sekira.ru

Изменения подготовлены для ветки `release`: контейнер `main` уже привязан к
`events.kira-sekira.ru` в `compose.release.yaml`. Домены и инфраструктура не меняются.

## Что переносится

- Главная и отдельная страница `/about` в зимней синей палитре.
- Согласованные тарифы: один час 10 000 ₽, от двух часов 7 000 ₽/час.
- 70 фотографий за час; первые 15 кадров за 3 дня; весь материал за 10 дней
  в личной онлайн-галерее.
- Восемь раскрывающихся FAQ, включая Nikon Z6 и фотовспышку.
- Четыре вопроса квиза, расчёт и переход в мессенджер с заполненным сообщением.
  Отправку сообщения подтверждает сам посетитель в своём мессенджере.
- Реальные галереи и контакты из существующего Directus; текущие URL
  `/portfolio/:slug` сохранены. Фото на странице «Обо мне» берётся из
  существующего `main_site.main_photo`.

## Контент

Поле `main_site.events_content` хранит весь бизнес-контент сайта корпоративов.
`directus/setup/content/events-site.json` содержит согласованную исходную копию.
Angular выводит HTML через стандартный sanitizer, без обхода очистки.
Для изменения стоимости согласованно обновите числовые параметры расчёта,
варианты квиза и HTML раздела с прайсом. HTML и JSON редактируются в Directus.
Прочие поля `main_site`, цены, отзывы, галереи и контакты не перезаписываются.

Скрипт `seed_events.py` заполняет поле только при значении `null`.
Повторный деплой сохраняет последующие изменения в админке. Пустой JSON не
считается отсутствующим содержимым и не заменяется автоматически.

## Первоначальная публикация

Workflow перед сборкой добавляет необязательное поле `events_content` в уже
работающий Directus и заполняет его согласованными текстами, только если поле
ещё не заполнено. Затем Angular пререндерит актуальный контент. Эта миграция
не меняет галереи, контакты или текущие значения других полей.

Публикация запускается обычным обновлением `release`. Секреты остаются
в существующем серверном окружении `.env` и GitHub Secrets. После применения
полной схемы workflow повторно вызывает сидер: существующий контент
сохраняется.

Для ручного запуска на сервере, где уже работают Directus и окружение проекта:

```
set -a; . ./.env; set +a
python3 directus/setup/seed_events.py --ensure-field
```

## Проверки

- Библиотека shared и Angular main компилируются.
- Пререндер с временной локальной API-фикстурой проверен для `/`, `/about`
  и существующего URL галереи. В выводе присутствуют восемь FAQ, новые
  заголовки и условия передачи фотографий.
- Production-сборка проверяется отдельно с той же фикстурой; production API
  и его настройки при проверке не изменяются.
- Браузерная проверка и проверка реального Directus после миграции остаются
  обязательными перед завершением публикации.

## После передачи репозитория

Registry prefix для контейнеров передаётся как IMAGE_PREFIX. Workflow
собирает и загружает образы в пространство текущего владельца репозитория
и использует краткоживущий GitHub Actions token для их загрузки на VPS.
Исходники публичного репозитория читаются по HTTPS без токена в URL.
Данные Directus и Docker volumes сохраняются.
